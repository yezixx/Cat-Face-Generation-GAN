# Cat Face Generation with GAN

데이터패턴인식 전공 과제로 진행한 GAN 기반 고양이 얼굴 이미지 생성 프로젝트입니다.

## 프로젝트 소개

GAN(Generative Adversarial Network)을 활용하여 고양이 얼굴 이미지를 학습하고, 학습된 생성 모델을 통해 새로운 고양이 얼굴 이미지를 생성합니다.

## 주요 내용

* 고양이 얼굴 이미지 데이터 전처리
* GAN 모델 구성 및 학습
* 생성자(Generator)와 판별자(Discriminator)의 적대적 학습
* 학습 과정에 따른 생성 이미지 변화 확인
* 학습된 GAN을 활용한 고양이 얼굴 이미지 생성

## 기술 스택

* Python
* Google Colab
* TensorFlow / Keras
* GAN
* NumPy
* Matplotlib
